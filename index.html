A FEW THINGS TO KNOW

Your questions, answered.

What’s free, exactly?

A free account includes 10 listing copy outputs and 3 Listing Upgrades each month. No card is required.

What is included in an upgrade?

Import a supported listing or add your photos and details. Studio uses the available photos as references to create one ghost mannequin main photo and refreshed title and description. Compare the original and new listing side by side.

Does Studio post for me?

Quick Save exports the new main photo and copies your title and description together. Choose Poshmark, eBay, Depop, Etsy or Vinted, then finish posting there.

What if a listing link won’t import?

Some marketplaces block imports. Add your photos and listing details manually to use the same workflows.

Will the description be accurate?

Photos, legible tags and your notes guide the copy. Check material, brand, sizing and flaws before posting.
