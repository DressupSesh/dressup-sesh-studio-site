What’s free, exactly?

A free account includes 10 listing copy outputs and 3 Listing Upgrades each month. No card is required.

What is included in an upgrade?

Import up to 16 listing photos and details, remove the backgrounds, refresh the title and description, and create a ghost mannequin image. Review and edit everything on one page.

Does Studio post for me?

Quick Post helps you save photos and copies your title and description. Choose Poshmark, eBay, Depop, Etsy or Vinted, then finish posting there.

What if a listing link won’t import?

Some marketplaces block imports. Add your photos and listing details manually to use the same workflows.

Will the description be accurate?

Photos, legible tags and your notes guide the copy. Check material, brand, sizing and flaws before posting.
